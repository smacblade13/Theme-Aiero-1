# aiero-index1

Standalone extraction of the Aiero `index1` homepage demo — "AI Consulting | Aiero AI Agency & Technology".

The demo is served at `/`. Everything it needs (components, contexts, data, styles and the
images it actually references) lives in this folder; nothing is shared with the source template.

## Run

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build    # static export -> out/
```

`next.config.ts` sets `output: "export"`, so `pnpm build` writes a plain static site to
`out/` that you can host anywhere.

## Pages included

- landing page only

## Dangling links

Menu and section links that pointed at routes this site does not serve were rewritten to `#`.
See `LINKS.md` for the full list and the original targets, so they can be restored if you add
those pages back.

## Adding inner pages later

Re-run the generator against the source template into a fresh folder:

```bash
node scripts/extract-site.mjs 1 --pages blog,shop,services,inner
```

It pulls in those route groups and leaves the corresponding links intact.
